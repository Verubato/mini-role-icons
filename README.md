# MiniRoleIcons

Simple addon that changes the role icons on unit frames.

Features:

- Custom high quality role icons.
- Specify custom size.
- Class coloured icons.
- Supports Shadowed Unit Frames.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
